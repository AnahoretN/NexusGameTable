# NexusGameTable - Краткое руководство

## Быстрый старт

### 1. Создание игры

1. Откройте приложение — локальная игра создаётся автоматически
2. Нажмите кнопку **Share** в правом меню, чтобы получить ссылку для друзей
3. Отправьте ссылку друзьям

### 2. Подключение к игре

1. Перейдите по ссылке вида: `https://example.com?hostId=...`
2. Введите ваше имя
3. Нажмите **Join**

### 3. Основные управления

| Действие | Как сделать |
|----------|-------------|
| Переместить объект | Перетащите мышью |
| Взять объект в курсор | Shift + клик на объекте |
| Положить объект из курсора | Shift + клик на цели |
| Открыть меню объекта | Правый клик |
| Масштаб | Ctrl + колёсико мыши (Ctrl + / − / 0 — зум и сброс) |
| Панорама | Ctrl + перетаскивание |
| Обычный курсор | Alt (удерживать) |

## Главное меню (правая панель)

### Create (Создание)

Создавайте объекты на столе:
- **Boards** — игровые доски
- **Tokens** — фишки (круг, квадрат, шестиугольник)
- **Dice** — кубики (d4, d6, d8, d10, d12, d20)
- **Counters** — счётчики
- **Decks** — стандартная колода карт
- **Spinners** — рулетка

### Hand (Рука)

- Ваши карты на руках
- Настройте размер карт (Scale)
- Перетащите карты для изменения порядка
- Правый клик для действий с картой

### Chat (Чат)

- Общайтесь между игроками
- Броски кубиков автоматически логируются сюда

### Players (Игроки)

- Список подключённых игроков
- Нажмите на кнопку роли, чтобы переключиться между GM и Player

### Tools (Инструменты)

Инструменты выбираются на **панели инструментов в левом верхнем углу** (какие кнопки показывать — настраивается в главном меню):

- **Cursor** — обычный режим курсора (также: удерживайте Alt)
- **Marker** — рисование
- **Eraser** — стирание
- **Ruler** — измерение расстояний
- **Zoom** — управление масштабом

## Контекстное меню (правый клик)

### Общие действия

- **Clone** — создать копию объекта
- **Delete** — удалить объект
- **Lock/Unlock** — заблокировать/разблокировать перемещение
- **Pin to Screen** — закрепить на экране (не двигается при панораме)

### Вращение

- **Rotate Clockwise** — по часовой стрелке (45°)
- **Rotate Counter-Clockwise** — против часовой (45°)
- **Swing Clockwise** — качание по часовой
- **Swing Counter-Clockwise** — качание против часовой

### Слои

- **Layer Up** —поднять выше (ближе к камере)
- **Layer Down** — опустить ниже (дальше от камеры)

### Карты

- **Flip** — перевернуть
- **Move to Hand** — переместить в руку
- **Return to Deck** — вернуть в колоду

### Колоды

- **Draw** — взять карту
- **Shuffle** — перетасовать
- **Play Top** — выложить верхнюю карту
- **Search** — поиск в колоде
- **Piles** — управление пулами (сбросами)

## Курсор-слот (Shift + Click)

Система позволяет быстро переносить объекты:

1. **Shift + Click** на карте/токене → объект помещается в курсор
2. **Shift + Click** на колоде/руке/столе → объект перемещается туда

**Индикация:**
- Фиолетовое кольцо → объект может принять предметы из курсора
- Число на курсоре → количество предметов

## Колоды и карты

### Создание колоды

1. Откройте **Create** → **Decks**
2. Нажмите **Standard Deck** (54 карты)
3. Колода появится на столе

### Действия с колодой

| Действие | Описание |
|----------|----------|
| Draw | Взять карту (Shift + клик или из меню) |
| Shuffle | Перетасовать |
| Play Top | Выложить верхнюю карту на стол |
| Search | Открыть окно поиска |
| Piles | Управить сбросами |

### Пулы (сбросы)

Каждая колода может иметь несколько пулов:

- **Discard** — стандартный сброс
- Custom piles — пользовательские пулы

Shift + клик на пуле → переместить выбранную карту туда.

## Рисование

1. Выберите инструмент **Marker** на панели инструментов (левый верхний угол)
2. Настройте цвет и толщину
3. Рисуйте на столе или объектах

**Модификаторы:**
- **Shift + Marker** — переместить рисунок
- **Shift + Eraser** — удалить рисунок целиком

## GM vs Player

### Game Master (GM)

Полный контроль:
- Создавать/удалять любые объекты
- Настраивать права игроков
- Видеть скрытые объекты
- Двигать заблокированные объекты

### Player

Ограниченные права (задаёт GM):
- Может создавать объекты (если разрешено)
- Может настраивать объекты (если разрешено)
- Может удалять объекты (если разрешено)

## Настройки объекта (Object Settings)

Откройте через **клик на шестерёнке** в контекстном меню.

### Вкладки

| Вкладка | Что настраивать |
|---------|-----------------|
| General | Имя, размер, позиция, вращение |
| Actions | Разрешённые действия, кнопки, двойной клик |
| States | Альтернативные состояния токена |
| Sliders | Числовые слайдеры (HP, MP и т.п.) |
| Piles | Управление сбросами (для колод) |
| Cards | Размер карт (для колод) |
| Import | Изображения объекта |
| Text | Текст на объекте |
| Values | Значения (числа, иконки) |
| Groups | Группировка объектов |

## Сохранение и загрузка

### Автосохранение

Игра автоматически сохраняется в localStorage раз в минуту (а также вручную из главного меню).

### Загрузка сохранённой игры

1. Откройте приложение
2. Если есть сохранение — оно загрузится автоматически
3. Чтобы начать новую игру — **Clear Saved State** в главном меню

## Сохранение для других игроков

### Экспорт состояния

1. Настройте игру как нужно
2. Сохраните состояние (автоматически)
3. Скопируйте значение из localStorage браузера

### Импорт состояния

1. Откройте DevTools → Application → Local Storage
2. Вставьте сохранённое значение `nexus-game-state` (или `nexus-game-state-compressed`)
3. Перезагрузите страницу

## Советы и трюки

### Быстрая раздача карт

Shift + клик на колоде → все карты попадают в курсор → Shift + клик на руке → все карты в руке

### Создание своих токенов

1. Create → Tokens
2. Выберите форму и цвет
3. Настройте размер
4. Нажмите Create Token

### Клонирование объектов

Правый клик → Clone → создаётся точная копия рядом с оригиналом

### Закрепление интерфейса

Правый клик на панели → Pin to Screen → панель остаётся на месте при панораме

### Изменение порядка слоёв

Если объект перекрывает другой:
- Правый клик → Layer Up (поднять)
- Правый клик → Layer Down (опустить)

| Shift + Marker | Переместить рисунок |
| Shift + Eraser | Удалить рисунок целиком |
| Правый клик | Контекстное меню |

## Частые проблемы

### Объект не двигается

- Проверьте, не заблокирован ли он (Lock)
- GM может двигать заблокированные объекты

### Не могу взять карту из колоды

- Убедитесь, что в колоде есть карты
- Проверьте права у GM

### Игроки не видят изменения

- Проверьте подключение (индикатор в правом меню)
- Обновите страницу

### Карты не отображаются

- Проверьте URL изображений
- Попробуйте другое изображение
