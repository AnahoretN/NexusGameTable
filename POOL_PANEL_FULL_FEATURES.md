# 🎮 Полный функционал пул-панелей

## ✅ Реализовано

### 📦 Поддерживаемые типы объектов

Теперь в пул-панели можно переносить **все типы игровых объектов**:

#### 🃏 Карты и Токены
- **Карточные колоды** (DECK)
- **Отдельные карты** (CARD)
- **Токены** (TOKEN)
- **Токены-шаблоны** (TOKEN_TYPE)

#### 🎲 Игровые механики
- **Кости** (DICE_OBJECT) - с поддержкой броска через контекстное меню
- **Счётчики** (COUNTER)
- **Рандомизаторы** (RANDOMIZER)

#### 🎨 Творческие инструменты
- **Рисунки** (DRAWING) - маркером нарисованные объекты
- **Поля боя** (BATTLEFIELD_CELL) - отдельные клетки полей боя
- **Доски** (BOARD) - игровые доски с сеткой

#### 🔗 Связанные объекты
- **Nexus доски** (NEXUS_BOARD) - составные доски из гексов
- **Nexus клетки** (NEXUS_CELL) - отдельные гекс-клетки

### 🖱️ Управление объектами

#### 📍 Drag & Drop
- **Перетаскивание**: перетащите любой объект для перемещения внутри пул-панели
- **Порог перетаскивания**: 5px для добавления в cursor slot
- **Ограничения**: объекты автоматически ограничиваются границами пул-панели

#### 🎯 Контекстное меню
**Правый клик** на любом объекте открывает полное контекстное меню:

**Базовые действия:**
- 🗑️ **Delete** - удалить объект
- 🔒 **Lock/Unlock** - заблокировать/разблокировать объект
- 📋 **Clone** - создать копию объекта со смещением
- 👁️ **Hide** - скрыть объект со стола

**Вращение:**
- 🔄 **Rotate Clockwise** - вращение по часовой стрелке
- 🔄 **Rotate Counter-Clockwise** - вращение против часовой стрелки
- 📐 **Rotation Step**: настраивается (45° по умолчанию)

**Слои:**
- ⬆️ **Bring to Front** - на передний план
- ⬇️ **Send to Back** - на задний план

**Специфичные действия:**
- 🃏 **Flip** - перевернуть карты (рубашкой/лицом)
- 🎲 **Roll** - бросить кости

#### ⌨️ Горячие клавиши
- **Ctrl + клик** / **⌘ + клик** - добавить объект в cursor slot
- **Shift + перетаскивание** - добавить в cursor slot после 5px
- **Правый клик** - контекстное меню

### 🚫 Ограничения

**НЕ поддерживаются в пул-панели:**
- ❌ **Панели** (PANEL) - UI объекты
- ❌ **Окна** (WINDOW) - модальные окна

Все остальные объекты - поддерживаются! 🎉

### 📊 Оптимизация

#### 🎯 Фильтрация объектов
```typescript
// Исключаем только UI объекты
if (obj.type === ItemType.PANEL || obj.type === ItemType.WINDOW) return false;

// Все остальные объекты - разрешены
return true;
```

#### ⚡ Cursor Slot
**Поддерживаемые типы для cursor slot:**
```typescript
[
  ItemType.CARD,           // Карточки
  ItemType.TOKEN,          // Токены
  ItemType.DECK,           // Колоды
  ItemType.DICE_OBJECT,    // Кости
  ItemType.RANDOMIZER,     // Рандомизаторы
  ItemType.DRAWING,       // Рисунки
  ItemType.BATTLEFIELD_CELL, // Поля боя
  ItemType.BOARD,          // Доски
  ItemType.NEXUS_BOARD,    // Nexus доски
  ItemType.NEXUS_CELL,     // Nexus клетки
  ItemType.COUNTER         // Счётчики
]
```

### 🎮 Примеры использования

#### 🎲 Создание зоны броска костей
1. Создайте пул-панель
2. Перетащите **кости** (DICE_OBJECT) в пул-панель
3. Используйте контекстное меню → **Roll** для броска

#### 🃏 Организация дополнительного стола
1. Создайте пул-панель для "запасного стола"
2. Перетащите **колоду** (DECK) в пул-панель
3. Раздавайте карты из этой колоды

#### 🎨 Создание тактической карты
1. Создайте пул-панель
2. Добавьте **поля боя** (BATTLEFIELD_CELL)
3. Используйте **рисунки** (DRAWING) для обозначения препятствий
