# 🌐 Игровое пространство NexusGameTable

## 📐 Архитектура

### Размеры
- **Весь мир**: `10000 × 10000 VU` (виртуальных единиц)
- **Доступная область**: `5000 × 5000 VU` (верхний левый квадрат)
- **Пул-панели**: `1000 × 1000 VU` каждая (за пределами доступной области)

### Виртуальные единицы (VU)
- `1 VU = 0.1%` высоты экрана
- Объекты масштабируются пропорционально размеру экрана
- Константа: `VU_PER_SCREEN_HEIGHT = 1000`

## 🎮 Ограничения для игроков

### Скроллинг и панорамирование
- **Игроки и ГМ** видят только доступную область `5000 × 5000 VU`
- Скроллбары автоматически ограничиваются этой областью
- Панорамирование (Shift+драг) не выходит за пределы
- Клавиатурная навигация также ограничена

### Рендеринг
- **Основной tabletop** рендерит только объекты в доступной области
- Объекты в пул-панелях рендерятся отдельно в своих компонентах
- Оптимизация производительности за счёт ограничения области просмотра

## 🖼️ Пул-панели

### Резервирование территории
Пул-панели автоматически резервируют территорию за пределами доступной области:

1. **Поиск доступного места**: система ищет свободный `1000 × 1000` участок
2. **Правила размещения**:
   - Справа от доступной области: `x ≥ 5000`
   - Снизу от доступной области: `y ≥ 5000`
   - Без пересечения с существующими пул-панелями

### Примеры координат
```
Пул-панель 1: (5000, 0)      - справа от доступной области
Пул-панель 2: (5000, 1000)   - под первой панелью
Пул-панель 3: (5000, 2000)   - под второй панелью
...
Пул-панель N: (6000, 0)      - новая колонка, когда заполнена первая
```

### Структура данных
```typescript
export interface PoolPanelData {
  tabs: PanelTab[];
  activeTabId: string;
  offsetX: number;          // X позиция в игровом мире (≥ 5000)
  offsetY: number;          // Y позиция в игровом мире (≥ 5000)
  territoryId?: string;     // ID зарезервированной территории
}
```

## ⚡ Производительность

### Оптимизация рендеринга
1. **Фильтрация объектов**: только объекты в доступной области
2. **Пространственное индексирование**: оптимизированная проверка попадания
3. **Мемоизация**: кэширование расчётов координат
4. **React.memo**: предотвращение лишних ререндеров

### Ограничение вычислений
- За пределами доступной области вычисления не выполняются
- Пул-панели рендерятся независимо от основного tabletop
- События мыши обрабатываются только в видимой области

## 📝 Использование

### Создание пул-панели
```typescript
// Автоматическое резервирование территории
const territory = findAvailableTerritory(existingPools);

const poolData: PoolPanelData = {
  tabs: [...],
  activeTabId: '...',
  offsetX: territory.x,  // Автоматически ≥ 5000
  offsetY: territory.y,  // Автоматически ≥ 5000
  territoryId: `territory-${panelId}`
};
```

### Ограничение скроллинга
```typescript
// В Tabletop.tsx
const constrained = clampScrollToPlayableArea(
  scrollX, scrollY,
  viewportWidth, viewportHeight,
  pixelsPerVU
);
```

### Фильтрация объектов
```typescript
// Только объекты в доступной области
const playableObjects = filterPlayableObjects(allObjects);
```
